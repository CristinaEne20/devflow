# DevFlow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build DevFlow, a Jira-inspired agile project management app (Kanban board with drag-and-drop, issue drawer, comments, filters, backlog, settings, global search) as a polished reference implementation of Next.js 16 + Prisma 7.

**Architecture:** Server Components read through typed query functions in `src/lib/queries/`; client components mutate through Server Actions in `src/actions/` that all go through one `runAction` wrapper (zod validation → Prisma → `revalidatePath` → `ActionResult`). Board filters and the open issue live in the URL (`?assignee=&type=&q=&issue=`), so every view is server-rendered and deep-linkable. Optimistic UI (`useOptimistic`) is used for drag-and-drop, drawer field edits, and comments.

**Tech Stack:** Next.js 16 (App Router, React 19, Turbopack), strict TypeScript, Tailwind CSS v4 (CSS-first config), shadcn/ui (Radix), lucide-react, @hello-pangea/dnd 18, PostgreSQL 17 (Docker), Prisma 7.10 with `@prisma/adapter-pg`, zod 4, next-themes, sonner, react-markdown + remark-gfm, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-08-devflow-design.md`

## Review Focus

1. **Stale board after a concurrent change** (a neighbor card was moved or deleted in another tab, then the user drops a card next to it) → the drop still succeeds and the card lands at the bottom of the target column. Pinned by Task 6, `moveIssue` "stale neighbor" test.
2. **Changing the type of an issue that has children** (Epic with stories → Task) → rejected with a clear message and nothing changes. Pinned by Task 6, `updateIssue` "children" test.
3. **Changing status from the drawer instead of dragging** → the issue goes to the bottom of the new column instead of keeping a position from the old column. Pinned by Task 6, `updateIssue` "status change" test.
4. **Hand-edited or garbage URL params** (`type=FOO`, `assignee=,,`, a 5 000-char `q`, lowercase `?issue=dev-101`) → ignored, clamped, or resolved case-insensitively; never a 500. Pinned by Task 4 `filters` tests and Task 8 `getIssueDetail` test.
5. **Stale "current user" cookie after re-seeding** (seed regenerates user IDs) → the app falls back to the first user instead of crashing. Pinned by Task 6 `current-user` test.

enum IssuePriority {
  LOW
  MEDIUM
  HIGH
  CRITICAL

model User {
  id        String   @id @default(cuid())
  name      String
  email     String   @unique
  avatarUrl String?
  createdAt DateTime @default(now())

  reportedIssues Issue[]   @relation("IssueReporter")
  assignedIssues Issue[]   @relation("IssueAssignee")
  comments       Comment[]
}

model Project {
  id           String   @id @default(cuid())
  name         String
  /// Uppercase prefix for issue keys, e.g. "DEV". Immutable after creation.
  key          String   @unique
  description  String?
  /// Last issue number handed out; incremented inside the create transaction.
  issueCounter Int      @default(0)
  createdAt    DateTime @default(now())

  id          String        @id @default(cuid())
  number      Int
  /// Denormalized "<project key>-<number>", e.g. "DEV-101".
  key         String        @unique
  title       String
  /// Markdown.
  description String?
  status      IssueStatus   @default(BACKLOG)
  priority    IssuePriority @default(MEDIUM)
  type        IssueType     @default(TASK)
  storyPoints Int?
  /// Fractional order within a status column (see src/lib/position.ts).
  position    Float

  projectId  String
  project    Project @relation(fields: [projectId], references: [id], onDelete: Cascade)
  reporterId String
  reporter   User    @relation("IssueReporter", fields: [reporterId], references: [id], onDelete: Restrict)
  assigneeId String?
  assignee   User?   @relation("IssueAssignee", fields: [assigneeId], references: [id], onDelete: SetNull)
  parentId   String?
  parent     Issue?  @relation("IssueHierarchy", fields: [parentId], references: [id], onDelete: SetNull)
  children   Issue[] @relation("IssueHierarchy")

  comments  Comment[]
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt

  @@unique([projectId, number])
  @@index([projectId, status, position])
  @@index([assigneeId])
  @@index([reporterId])
  @@index([parentId])
  @@index([title(ops: raw("gin_trgm_ops"))], type: Gin)

  id        String   @id @default(cuid())

  issueId   String

  authorId  String
  author    User     @relation(fields: [authorId], references: [id], onDelete: Cascade)

// Client-safe enum values. Types come from the generated Prisma client via
// `import type`, so nothing server-side is bundled into client components.
import type { IssuePriority, IssueStatus, IssueType } from "@/generated/prisma/enums";

export type { IssuePriority, IssueStatus, IssueType };

/** Board column order. */
export const ISSUE_STATUSES = [
  "BACKLOG",
  "TODO",
  "IN_PROGRESS",
  "IN_REVIEW",
  "DONE",
] as const satisfies readonly IssueStatus[];

export const ISSUE_TYPES = [
  "EPIC",
  "STORY",
  "BUG",
  "TASK",
  "SUBTASK",
] as const satisfies readonly IssueType[];

export const ISSUE_PRIORITIES = [
  "LOW",
  "MEDIUM",
  "HIGH",
  "CRITICAL",
] as const satisfies readonly IssuePriority[];

function includes<T extends string>(values: readonly T[], value: unknown): value is T {
  return typeof value === "string" && (values as readonly string[]).includes(value);
}

export function isIssueStatus(value: unknown): value is IssueStatus {
  return includes(ISSUE_STATUSES, value);
}

export function isIssueType(value: unknown): value is IssueType {
  return includes(ISSUE_TYPES, value);
}

export function isIssuePriority(value: unknown): value is IssuePriority {
  return includes(ISSUE_PRIORITIES, value);
}

import { PrismaPg } from "@prisma/adapter-pg";
import { PrismaClient } from "@/generated/prisma/client";

function createClient(): PrismaClient {

// Fractional indexing: each issue stores a float `position` within its status
// column. Inserting between two neighbors takes the midpoint, so a move updates
// exactly one row. When repeated midpoints exhaust float precision the column
// is renumbered (see `needsRebalance`).

export const POSITION_STEP = 1024;
export const MIN_POSITION_GAP = 1e-6;

/** Position for an item placed between `before` and `after` (null = no neighbor on that side). */
export function positionBetween(before: number | null, after: number | null): number {
  if (before === null) return after === null ? POSITION_STEP : after - POSITION_STEP;
  if (after === null) return before + POSITION_STEP;
  return (before + after) / 2;
}

/** True when the neighbors are too close (or out of order) to split. */
export function needsRebalance(before: number | null, after: number | null): boolean {
  if (before === null || after === null) return false;
  return after - before <= MIN_POSITION_GAP;
}

/** Evenly spaced position for the item at `index` in a renumbered column. */
export function positionForIndex(index: number): number {
  return (index + 1) * POSITION_STEP;
}

```ts
import { ISSUE_STATUSES, type IssueStatus } from "@/lib/domain";

export type Columns<T> = Record<IssueStatus, T[]>;

/** A drag result. `to.index` is the final index after the item is removed from its source. */
export type BoardMove = {
  issueId: string;
  from: { status: IssueStatus; index: number };
  to: { status: IssueStatus; index: number };
};

type Movable = { id: string; status: IssueStatus };

export function groupByStatus<T extends { status: IssueStatus }>(items: readonly T[]): Columns<T> {
  const columns = Object.fromEntries(ISSUE_STATUSES.map((status) => [status, [] as T[]])) as Columns<T>;
  for (const item of items) columns[item.status].push(item);
  return columns;
}

export function moveInColumns<T extends Movable>(columns: Columns<T>, move: BoardMove): Columns<T> {
  const source = [...columns[move.from.status]];
  const sourceIndex = source.findIndex((item) => item.id === move.issueId);
  const [item] = sourceIndex === -1 ? [] : source.splice(sourceIndex, 1);
  if (!item) return columns;

  const moved: T = { ...item, status: move.to.status };

  if (move.from.status === move.to.status) {
    source.splice(move.to.index, 0, moved);
    return { ...columns, [move.from.status]: source };
  }

  const destination = [...columns[move.to.status]];
  destination.splice(move.to.index, 0, moved);
  return { ...columns, [move.from.status]: source, [move.to.status]: destination };
}

/** Ids of the items directly above and below the moved item once the move is applied. */
export function neighborsAfterMove<T extends Movable>(
  columns: Columns<T>,
  move: BoardMove,
): { beforeId: string | null; afterId: string | null } {
  const column = moveInColumns(columns, move)[move.to.status];
  return {
    beforeId: column[move.to.index - 1]?.id ?? null,
    afterId: column[move.to.index + 1]?.id ?? null,
  };
}

// Board/backlog filters live in the URL so filtered views are shareable and
// server-rendered. This module is the only place that knows the param format:
//   ?assignee=<userId>,<userId>,unassigned&type=BUG,STORY&q=text
import type { Prisma } from "@/generated/prisma/client";
import { isIssueType, type IssueType } from "@/lib/domain";

export const UNASSIGNED = "unassigned";
export const MAX_QUERY_LENGTH = 100;

export type SearchParamsRecord = Record<string, string | string[] | undefined>;

export type BoardFilters = {
  assigneeIds: string[];
  includeUnassigned: boolean;
  types: IssueType[];
  q: string;
};

export const EMPTY_FILTERS: BoardFilters = {
  assigneeIds: [],
  includeUnassigned: false,
  types: [],
  q: "",
};

function readParam(source: SearchParamsRecord | URLSearchParams, key: string): string {
  if (source instanceof URLSearchParams) return source.get(key) ?? "";
  const value = source[key];
  return Array.isArray(value) ? (value[0] ?? "") : (value ?? "");
}

function splitList(value: string): string[] {
  return [...new Set(value.split(",").map((part) => part.trim()).filter(Boolean))];
}

export function parseFilters(source: SearchParamsRecord | URLSearchParams): BoardFilters {
  const assigneeTokens = splitList(readParam(source, "assignee"));
  return {
    assigneeIds: assigneeTokens.filter((token) => token !== UNASSIGNED),
    includeUnassigned: assigneeTokens.includes(UNASSIGNED),
    types: splitList(readParam(source, "type")).filter(isIssueType),
    q: readParam(source, "q").trim().slice(0, MAX_QUERY_LENGTH),
  };
}

function setOrDelete(params: URLSearchParams, key: string, value: string) {
  if (value) params.set(key, value);
  else params.delete(key);
}

/** Returns a copy of `base` with the filter params replaced; other params are kept. */
export function writeFilters(base: string | URLSearchParams, filters: BoardFilters): URLSearchParams {
  const params = new URLSearchParams(base);
  const assignees = [...filters.assigneeIds, ...(filters.includeUnassigned ? [UNASSIGNED] : [])];
  setOrDelete(params, "assignee", assignees.join(","));
  setOrDelete(params, "type", filters.types.join(","));
  setOrDelete(params, "q", filters.q.trim());
  return params;
}

export function hasActiveFilters(filters: BoardFilters): boolean {
  return (
    filters.assigneeIds.length > 0 || filters.includeUnassigned || filters.types.length > 0 || filters.q !== ""
  );
}

export function toIssueWhere(projectId: string, filters: BoardFilters): Prisma.IssueWhereInput {
  const conditions: Prisma.IssueWhereInput[] = [];

  if (filters.assigneeIds.length > 0 || filters.includeUnassigned) {
    conditions.push({
      OR: [
        ...(filters.assigneeIds.length > 0 ? [{ assigneeId: { in: filters.assigneeIds } }] : []),
        ...(filters.includeUnassigned ? [{ assigneeId: null }] : []),
      ],
    });
  }

  if (filters.types.length > 0) {
    conditions.push({ type: { in: filters.types } });
  }

  if (filters.q) {
    conditions.push({
      OR: [
        { title: { contains: filters.q, mode: "insensitive" } },
        { key: { startsWith: filters.q, mode: "insensitive" } },
      ],
    });
  }

  return conditions.length > 0 ? { projectId, AND: conditions } : { projectId };
}

import type { SearchParamsRecord } from "@/lib/filters";

export type ProjectSection = "board" | "backlog" | "settings";

export function toURLSearchParams(source: string | URLSearchParams | SearchParamsRecord): URLSearchParams {
  if (typeof source === "string" || source instanceof URLSearchParams) return new URLSearchParams(source);
  const params = new URLSearchParams();
  for (const [key, value] of Object.entries(source)) {
    const first = Array.isArray(value) ? value[0] : value;
    if (first !== undefined) params.set(key, first);
  }
  return params;
}

/** Query string (with leading "?", or "") that opens `issueKey` in the drawer, or closes it when null. */
export function withIssueParam(
  source: string | URLSearchParams | SearchParamsRecord,
  issueKey: string | null,
): string {
  const params = toURLSearchParams(source);
  if (issueKey) params.set("issue", issueKey);
  else params.delete("issue");
  const query = params.toString();
  return query ? `?${query}` : "";
}

export function projectUrl(projectKey: string, section: ProjectSection): string {
  return `/projects/${projectKey}/${section}`;
}

export function boardIssueUrl(projectKey: string, issueKey: string): string {
  return `${projectUrl(projectKey, "board")}${withIssueParam("", issueKey)}`;
}

const RELATIVE_UNITS = [
  ["year", 31_536_000],
  ["month", 2_592_000],
  ["week", 604_800],
  ["day", 86_400],
  ["hour", 3_600],
  ["minute", 60],
] as const;

const relativeFormatter = new Intl.RelativeTimeFormat("en", { numeric: "auto" });
const dateFormatter = new Intl.DateTimeFormat("en", { dateStyle: "medium", timeStyle: "short" });

export function formatRelativeTime(date: Date, now: Date = new Date()): string {
  const diffSeconds = Math.round((date.getTime() - now.getTime()) / 1000);
  const absolute = Math.abs(diffSeconds);
  for (const [unit, seconds] of RELATIVE_UNITS) {
    if (absolute >= seconds) return relativeFormatter.format(Math.round(diffSeconds / seconds), unit);
  }
  return "just now";
}

export function formatDate(date: Date): string {
  return dateFormatter.format(date);
}

export function getInitials(name: string): string {
  const words = name.trim().split(/\s+/).filter(Boolean);
  const first = words[0]?.[0] ?? "";
  const last = words.length > 1 ? (words[words.length - 1]?.[0] ?? "") : "";
  return (first + last).toUpperCase() || "?";
}

import { z } from "zod";
import { ISSUE_PRIORITIES, ISSUE_STATUSES, ISSUE_TYPES, type IssueType } from "@/lib/domain";

export const TITLE_MAX = 255;
export const DESCRIPTION_MAX = 20_000;
export const COMMENT_MAX = 5_000;
export const PROJECT_NAME_MAX = 80;
export const PROJECT_DESCRIPTION_MAX = 2_000;
export const STORY_POINTS_MAX = 100;

const id = z.string().min(1, "Missing id");
const optionalId = z.string().min(1).nullable();

const title = z
  .string()
  .trim()
  .min(1, "Title is required")
  .max(TITLE_MAX, `Title must be at most ${TITLE_MAX} characters`);

/** Markdown text where blank means "no value". */
const optionalMarkdown = (max: number, label: string) =>
  z
    .string()
    .max(max, `${label} must be at most ${max.toLocaleString("en")} characters`)
    .nullable()
    .transform((value) => (value === null || value.trim() === "" ? null : value));

const storyPoints = z
  .number({ error: "Story points must be a number" })
  .int("Story points must be a whole number")
  .min(0, "Story points cannot be negative")
  .max(STORY_POINTS_MAX, `Story points must be at most ${STORY_POINTS_MAX}`)
  .nullable();

const issueType = z.enum(ISSUE_TYPES);
const issueStatus = z.enum(ISSUE_STATUSES);
const issuePriority = z.enum(ISSUE_PRIORITIES);

export const createIssueSchema = z.object({
  projectId: id,
  title,
  description: optionalMarkdown(DESCRIPTION_MAX, "Description").optional(),
  type: issueType,
  status: issueStatus,
  priority: issuePriority,
  assigneeId: optionalId,
  storyPoints,
  parentId: optionalId,
});

export const issuePatchSchema = z
  .object({
    title,
    description: optionalMarkdown(DESCRIPTION_MAX, "Description"),
    type: issueType,
    status: issueStatus,
    priority: issuePriority,
    assigneeId: optionalId,
    storyPoints,
    parentId: optionalId,
  })
  .partial()
  .refine((patch) => Object.values(patch).some((value) => value !== undefined), "Nothing to update");

export const updateIssueSchema = z.object({ id, patch: issuePatchSchema });

export const moveIssueSchema = z.object({
  issueId: id,
  toStatus: issueStatus,
  beforeId: optionalId,
  afterId: optionalId,
});

export const deleteIssueSchema = z.object({ id });

export const addCommentSchema = z.object({
  issueId: id,
  content: z
    .string()
    .trim()
    .min(1, "Comment cannot be empty")
    .max(COMMENT_MAX, `Comment must be at most ${COMMENT_MAX.toLocaleString("en")} characters`),
});

export const deleteCommentSchema = z.object({ commentId: id });

export const updateProjectSchema = z.object({
  projectId: id,
  name: z
    .string()
    .trim()
    .min(1, "Project name is required")
    .max(PROJECT_NAME_MAX, `Project name must be at most ${PROJECT_NAME_MAX} characters`),
  description: optionalMarkdown(PROJECT_DESCRIPTION_MAX, "Description"),
});

export const switchUserSchema = z.object({ userId: id });

export type CreateIssueInput = z.input<typeof createIssueSchema>;
export type IssuePatch = z.input<typeof issuePatchSchema>;
export type UpdateIssueInput = z.input<typeof updateIssueSchema>;
export type MoveIssueInput = z.input<typeof moveIssueSchema>;
export type DeleteIssueInput = z.input<typeof deleteIssueSchema>;
export type AddCommentInput = z.input<typeof addCommentSchema>;
export type DeleteCommentInput = z.input<typeof deleteCommentSchema>;
export type UpdateProjectInput = z.input<typeof updateProjectSchema>;
export type SwitchUserInput = z.input<typeof switchUserSchema>;

// ---------------------------------------------------------------------------
// Issue hierarchy: EPIC ← STORY/TASK/BUG ← SUBTASK. Epics have no parent, so
// cycles are impossible as long as these rules hold.

export type ParentInfo = { type: IssueType; projectId: string };

const SUBTASK_PARENT_TYPES: readonly IssueType[] = ["STORY", "TASK", "BUG"];

/** Returns an error message, or null when `type` may sit under `parent`. */
export function validateHierarchy(type: IssueType, parent: ParentInfo | null, projectId: string): string | null {
  if (parent && parent.projectId !== projectId) return "Parent issue must belong to the same project";

  switch (type) {
    case "EPIC":
      return parent ? "Epics cannot have a parent" : null;
    case "SUBTASK":
      if (!parent) return "A subtask must have a parent issue";
      return SUBTASK_PARENT_TYPES.includes(parent.type) ? null : "A subtask's parent must be a story, task, or bug";
    default:
      return parent && parent.type !== "EPIC" ? "Only epics can be the parent of a story, task, or bug" : null;
  }
}

export function canBeParentOf(parentType: IssueType, childType: IssueType): boolean {
  return validateHierarchy(childType, { type: parentType, projectId: "" }, "") === null;
}

// Values are passed through as-is; the action's zod schema is the validator.
import type { CreateIssueInput, UpdateProjectInput } from "@/lib/validation";

/** Select value meaning "no selection" (Radix Select items cannot use ""). */
export const NONE = "none";

function field(formData: FormData, name: string): string {
  const value = formData.get(name);
  return typeof value === "string" ? value : "";
}

function optionalId(value: string): string | null {
  return value === "" || value === NONE ? null : value;
}

export function parseStoryPoints(raw: string): number | null {
  const trimmed = raw.trim();
  return trimmed === "" ? null : Number(trimmed);
}

export function createIssueInputFromForm(formData: FormData, projectId: string): CreateIssueInput {
  return {
    projectId,
    title: field(formData, "title"),
    description: field(formData, "description"),
    type: field(formData, "type") as CreateIssueInput["type"],
    status: field(formData, "status") as CreateIssueInput["status"],
    priority: field(formData, "priority") as CreateIssueInput["priority"],

    storyPoints: parseStoryPoints(field(formData, "storyPoints")),
    parentId: optionalId(field(formData, "parentId")),

}

import { z } from "zod";

/** The return type of every Server Action. Actions never throw to the client. */
export type ActionResult<T = void> =
  | { ok: true; data: T }
  | { ok: false; error: string; fieldErrors?: Record<string, string[]> };

export const GENERIC_ERROR = "Something went wrong. Please try again.";

/** An expected, user-facing failure (not found, rule violation, …). */
export class DomainError extends Error {}

export function ok<T>(data: T): ActionResult<T> {
  return { ok: true, data };
}

export function fail(error: string, fieldErrors?: Record<string, string[]>): ActionResult<never> {
  return fieldErrors ? { ok: false, error, fieldErrors } : { ok: false, error };
}

export function failFromZod(error: z.ZodError): ActionResult<never> {
  const flat = z.flattenError(error);
  const fieldErrors: Record<string, string[]> = {};
  for (const [key, messages] of Object.entries(flat.fieldErrors)) {
    if (Array.isArray(messages) && messages.length > 0) fieldErrors[key] = messages;
  }
  const message = flat.formErrors[0] ?? Object.values(fieldErrors)[0]?.[0] ?? "Invalid input";
  return fail(message, fieldErrors);
}

/** Runs an action body and maps every outcome onto an ActionResult. */
export async function runAction<T>(body: () => Promise<T>): Promise<ActionResult<T>> {
  try {
    return ok(await body());
  } catch (error) {
    if (error instanceof DomainError) return fail(error.message);
    if (error instanceof z.ZodError) return failFromZod(error);
    console.error("[action] unexpected error", error);
    return fail(GENERIC_ERROR);
  }
}

import { cookies } from "next/headers";
import { cache } from "react";
import type { User } from "@/generated/prisma/client";
import { CURRENT_USER_COOKIE } from "@/lib/constants";
import { db } from "@/lib/db";

/**
 * DevFlow has no authentication: the visitor "acts as" a seeded user chosen in
 * the user menu (stored in a cookie). Falls back to the earliest user, which
 * also covers stale cookies after the database is re-seeded.
 */
export const getCurrentUser = cache(async (): Promise<User> => {
  const userId = (await cookies()).get(CURRENT_USER_COOKIE)?.value;
  if (userId) {
    const user = await db.user.findUnique({ where: { id: userId } });
    if (user) return user;
  }

  const fallback = await db.user.findFirst({ orderBy: [{ createdAt: "asc" }, { email: "asc" }] });
  if (!fallback) throw new Error("No users found. Run `npx prisma db seed` to populate the database.");
  return fallback;
});

"use server";

import type { Prisma } from "@/generated/prisma/client";
import { DomainError, runAction, type ActionResult } from "@/lib/action-result";
import { getCurrentUser } from "@/lib/current-user";
import { db } from "@/lib/db";
import type { IssueStatus } from "@/lib/domain";
import { needsRebalance, positionBetween, positionForIndex } from "@/lib/position";
import { revalidateProject } from "@/lib/revalidate";
import {
  createIssueSchema,
  deleteIssueSchema,
  moveIssueSchema,
  updateIssueSchema,
  validateHierarchy,
  type CreateIssueInput,
  type DeleteIssueInput,
  type MoveIssueInput,
  type UpdateIssueInput,
} from "@/lib/validation";

type Tx = Prisma.TransactionClient;

const columnOrder = [{ position: "asc" }, { createdAt: "asc" }] satisfies Prisma.IssueOrderByWithRelationInput[];

async function bottomPosition(tx: Tx, projectId: string, status: IssueStatus, excludeId?: string) {
  const last = await tx.issue.findFirst({
    where: { projectId, status, ...(excludeId ? { NOT: { id: excludeId } } : {}) },
    orderBy: { position: "desc" },
    select: { position: true },
  });
  return positionBetween(last?.position ?? null, null);
}

async function loadParent(tx: Tx, parentId: string | null) {
  if (!parentId) return null;
  const parent = await tx.issue.findUnique({ where: { id: parentId }, select: { type: true, projectId: true } });
  if (!parent) throw new DomainError("Parent issue not found");
  return parent;
}

async function assertAssigneeExists(tx: Tx, assigneeId: string | null | undefined) {
  if (!assigneeId) return;
  const user = await tx.user.findUnique({ where: { id: assigneeId }, select: { id: true } });
  if (!user) throw new DomainError("Assignee not found");
}

/** Renumbers a column evenly, inserting `movedId` directly after `beforeId` (or first). */
async function rebalanceColumn(
  tx: Tx,
  projectId: string,
  status: IssueStatus,
  movedId: string,
  beforeId: string | null,
) {
  const others = await tx.issue.findMany({
    where: { projectId, status, NOT: { id: movedId } },
    orderBy: columnOrder,
    select: { id: true },
  });
  const ids = others.map((issue) => issue.id);
  ids.splice(beforeId ? ids.indexOf(beforeId) + 1 : 0, 0, movedId);

  for (const [index, id] of ids.entries()) {
    await tx.issue.update({
      where: { id },
      data: { position: positionForIndex(index), ...(id === movedId ? { status } : {}) },
    });
  }
}

export async function createIssue(input: CreateIssueInput): Promise<ActionResult<{ key: string }>> {
  return runAction(async () => {
    const data = createIssueSchema.parse(input);
    const reporter = await getCurrentUser();

    const issue = await db.$transaction(async (tx) => {
      const exists = await tx.project.findUnique({ where: { id: data.projectId }, select: { id: true } });
      if (!exists) throw new DomainError("Project not found");

      const hierarchyError = validateHierarchy(data.type, await loadParent(tx, data.parentId), data.projectId);
      if (hierarchyError) throw new DomainError(hierarchyError);
      await assertAssigneeExists(tx, data.assigneeId);

      // Incrementing the counter row-locks the project, so concurrent creates
      // are serialized and each gets a unique number.
      const project = await tx.project.update({
        where: { id: data.projectId },
        data: { issueCounter: { increment: 1 } },
        select: { key: true, issueCounter: true },
      });

      return tx.issue.create({
        data: {
          projectId: data.projectId,
          number: project.issueCounter,
          key: `${project.key}-${project.issueCounter}`,
          title: data.title,
          description: data.description ?? null,
          type: data.type,
          status: data.status,
          priority: data.priority,
          storyPoints: data.storyPoints,
          assigneeId: data.assigneeId,
          parentId: data.parentId,
          reporterId: reporter.id,
          position: await bottomPosition(tx, data.projectId, data.status),
        },
        select: { key: true, project: { select: { key: true } } },
      });
    });

    revalidateProject(issue.project.key);
    return { key: issue.key };
  });
}

export async function updateIssue(input: UpdateIssueInput): Promise<ActionResult<{ key: string }>> {
  return runAction(async () => {
    const { id, patch } = updateIssueSchema.parse(input);

    const issue = await db.$transaction(async (tx) => {
      const current = await tx.issue.findUnique({
        where: { id },
        select: { projectId: true, type: true, status: true, parentId: true, children: { select: { type: true } } },
      });
      if (!current) throw new DomainError("Issue not found");

      if (patch.type !== undefined || patch.parentId !== undefined) {
        const nextType = patch.type ?? current.type;
        const nextParentId = patch.parentId === undefined ? current.parentId : patch.parentId;
        if (nextParentId === id) throw new DomainError("An issue cannot be its own parent");

        const hierarchyError = validateHierarchy(nextType, await loadParent(tx, nextParentId), current.projectId);
        if (hierarchyError) throw new DomainError(hierarchyError);

        const asParent = { type: nextType, projectId: current.projectId };
        if (current.children.some((child) => validateHierarchy(child.type, asParent, current.projectId) !== null)) {
          throw new DomainError("Can't change type: existing child issues wouldn't be valid under the new type");
        }
      }

      await assertAssigneeExists(tx, patch.assigneeId);

      // A status change from the drawer (not a drag) appends to the new column.
      const position =
        patch.status !== undefined && patch.status !== current.status
          ? await bottomPosition(tx, current.projectId, patch.status, id)
          : undefined;

      return tx.issue.update({
        where: { id },
        data: { ...patch, position },
        select: { key: true, project: { select: { key: true } } },
      });
    });

    revalidateProject(issue.project.key);
    return { key: issue.key };
  });
}

export async function moveIssue(input: MoveIssueInput): Promise<ActionResult> {
  return runAction(async () => {
    const { issueId, toStatus, beforeId, afterId } = moveIssueSchema.parse(input);

    const projectKey = await db.$transaction(async (tx) => {
      const issue = await tx.issue.findUnique({
        where: { id: issueId },
        select: { projectId: true, project: { select: { key: true } } },
      });
      if (!issue) throw new DomainError("Issue not found");

      // Neighbors are re-read from the database: client positions are never trusted.
      const neighborIds = [beforeId, afterId].filter((value): value is string => value !== null);
      const neighbors = await tx.issue.findMany({
        where: { id: { in: neighborIds }, projectId: issue.projectId, status: toStatus, NOT: { id: issueId } },
        select: { id: true, position: true },
      });
      const before = beforeId ? neighbors.find((n) => n.id === beforeId) : undefined;
      const after = afterId ? neighbors.find((n) => n.id === afterId) : undefined;
      const isStale = (beforeId !== null && !before) || (afterId !== null && !after);

      if (isStale) {
        // The client's view of the column is out of date; append instead of failing the drop.
        await tx.issue.update({
          where: { id: issueId },
          data: { status: toStatus, position: await bottomPosition(tx, issue.projectId, toStatus, issueId) },
        });
      } else {
        const beforePosition = before?.position ?? null;
        const afterPosition = after?.position ?? null;
        if (needsRebalance(beforePosition, afterPosition)) {
          await rebalanceColumn(tx, issue.projectId, toStatus, issueId, beforeId);
        } else {
          await tx.issue.update({
            where: { id: issueId },
            data: { status: toStatus, position: positionBetween(beforePosition, afterPosition) },
          });
        }
      }

      return issue.project.key;
    });

    revalidateProject(projectKey);
  });
}

export async function deleteIssue(input: DeleteIssueInput): Promise<ActionResult> {
  return runAction(async () => {
    const { id } = deleteIssueSchema.parse(input);
    const issue = await db.issue.findUnique({ where: { id }, select: { project: { select: { key: true } } } });
    if (!issue) throw new DomainError("Issue not found");

    // Comments cascade; children are orphaned (onDelete: SetNull) rather than deleted.
    await db.issue.delete({ where: { id } });
    revalidateProject(issue.project.key);
  });
}

"use server";

import { DomainError, runAction, type ActionResult } from "@/lib/action-result";
import { getCurrentUser } from "@/lib/current-user";

  addCommentSchema,

export async function addComment(input: AddCommentInput): Promise<ActionResult<{ id: string }>> {
  return runAction(async () => {
    const data = addCommentSchema.parse(input);
    const author = await getCurrentUser();

    const issue = await db.issue.findUnique({
      where: { id: data.issueId },
      select: { project: { select: { key: true } } },

    if (!issue) throw new DomainError("Issue not found");

    const comment = await db.comment.create({
      data: { issueId: data.issueId, content: data.content, authorId: author.id },
      select: { id: true },
    });

    revalidateProject(issue.project.key);
    return comment;
  });

export async function deleteComment(input: DeleteCommentInput): Promise<ActionResult> {
  return runAction(async () => {
    const { commentId } = deleteCommentSchema.parse(input);
    const currentUser = await getCurrentUser();

    const comment = await db.comment.findUnique({
      where: { id: commentId },
      select: { authorId: true, issue: { select: { project: { select: { key: true } } } } },

import "server-only";
import type { Prisma } from "@/generated/prisma/client";
import { db } from "@/lib/db";
import { MAX_QUERY_LENGTH } from "@/lib/filters";
import { userSummarySelect } from "@/lib/queries/users";

export const SEARCH_LIMIT = 50;

const searchResultSelect = {
  id: true,
  key: true,
  title: true,
  type: true,
  status: true,
  priority: true,
  project: { select: { key: true, name: true } },
  assignee: { select: userSummarySelect },
} satisfies Prisma.IssueSelect;

export type SearchResult = Prisma.IssueGetPayload<{ select: typeof searchResultSelect }>;

/** Global search: title contains the query (trigram-indexed) or key starts with it. */
export async function searchIssues(query: string): Promise<SearchResult[]> {
  const q = query.trim().slice(0, MAX_QUERY_LENGTH);
  if (!q) return [];
  return db.issue.findMany({
    where: {
      OR: [
        { title: { contains: q, mode: "insensitive" } },
        { key: { startsWith: q, mode: "insensitive" } },
      ],
    },
    orderBy: { updatedAt: "desc" },
    take: SEARCH_LIMIT,
    select: searchResultSelect,
  });
}

async function main() {
  // Children first; issue self-references are SET NULL so order within issues doesn't matter.
  await prisma.comment.deleteMany();
  await prisma.issue.deleteMany();
  await prisma.project.deleteMany();
  await prisma.user.deleteMany();

  const userIds = {} as Record<UserRef, string>;
  for (const [index, [ref, user]] of (Object.entries(USERS) as [UserRef, (typeof USERS)[UserRef]][]).entries()) {
    const created = await prisma.user.create({
      data: { ...user, avatarUrl: avatarUrl(user.name), createdAt: ago((60 - index) * DAY) },
    });
    userIds[ref] = created.id;
  }

  const project = await prisma.project.create({
    data: {
      key: "DEV",
      name: "DevFlow Platform",
      description:
        "The core DevFlow web application: boards, backlog, issue tracking and collaboration features.",
      issueCounter: FIRST_ISSUE_NUMBER - 1 + ISSUES.length,
    },
  });

  const issueIds = new Map<string, string>();
  const columnSizes = new Map<IssueStatus, number>();

  for (const [index, issue] of ISSUES.entries()) {
    const number = FIRST_ISSUE_NUMBER + index;
    const slot = (columnSizes.get(issue.status) ?? 0) + 1;
    columnSizes.set(issue.status, slot);

    const parentId = issue.parent ? issueIds.get(issue.parent) : undefined;
    if (issue.parent && !parentId) {
      throw new Error(`Seed issue "${issue.ref}" references parent "${issue.parent}" before it is declared.`);
    }

    const created = await prisma.issue.create({
      data: {
        projectId: project.id,
        number,
        key: `${project.key}-${number}`,
        title: issue.title,
        description: issue.description ?? null,
        type: issue.type,
        status: issue.status,
        priority: issue.priority,
        storyPoints: issue.points,
        position: slot * POSITION_STEP,
        reporterId: userIds[issue.reporter],
        assigneeId: issue.assignee ? userIds[issue.assignee] : null,
        parentId: parentId ?? null,
        createdAt: ago(issue.createdDaysAgo * DAY),
      },
    });
    issueIds.set(issue.ref, created.id);
  }

  for (const comment of COMMENTS) {
    const issueId = issueIds.get(comment.issue);
    if (!issueId) throw new Error(`Seed comment references unknown issue "${comment.issue}".`);
    await prisma.comment.create({
      data: {
        issueId,
        authorId: userIds[comment.author],
        content: comment.content,
        createdAt: ago(comment.hoursAgo * HOUR),
      },
    });
  }

  console.log(
    `Seeded ${Object.keys(USERS).length} users, project ${project.key}, ${ISSUES.length} issues and ${COMMENTS.length} comments.`,
  );
}

main()
  .catch((error) => {
    console.error(error);
    process.exitCode = 1;
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

"use client";

import type { KeyboardEvent } from "react";
import { Markdown } from "@/components/shared/markdown";
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";
import { Textarea } from "@/components/ui/textarea";

type MarkdownEditorProps = {
  value: string;
  onChange: (value: string) => void;
  /** Called on ⌘/Ctrl+Enter. */
  onSubmit?: () => void;
  /** When set, a hidden input carries the value so the editor works inside <form>. */
  name?: string;
  placeholder?: string;
  autoFocus?: boolean;
  rows?: number;
  maxLength?: number;
  "aria-label"?: string;
};

export function MarkdownEditor({
  value,
  onChange,
  onSubmit,
  name,
  placeholder = "Write in Markdown…",
  autoFocus,
  rows = 6,
  maxLength,
  "aria-label": ariaLabel,
}: MarkdownEditorProps) {
  function handleKeyDown(event: KeyboardEvent<HTMLTextAreaElement>) {
    if (event.key === "Enter" && (event.metaKey || event.ctrlKey) && onSubmit) {
      event.preventDefault();
      onSubmit();
    }
  }

  return (
    <Tabs defaultValue="write" className="gap-2">
      {name && <input type="hidden" name={name} value={value} />}
      <TabsList className="h-8">
        <TabsTrigger value="write" className="text-xs">
          Write
        </TabsTrigger>
        <TabsTrigger value="preview" className="text-xs">
          Preview
        </TabsTrigger>
      </TabsList>
      <TabsContent value="write">
        <Textarea
          value={value}
          onChange={(event) => onChange(event.target.value)}
          onKeyDown={handleKeyDown}
          placeholder={placeholder}
          autoFocus={autoFocus}
          rows={rows}
          maxLength={maxLength}
          aria-label={ariaLabel}
          className="min-h-24 resize-y font-mono text-[13px] leading-relaxed"
        />
      </TabsContent>
      <TabsContent value="preview">
        <div className="min-h-24 rounded-md border px-3 py-2">
          {value.trim() ? (
            <Markdown>{value}</Markdown>
          ) : (
            <p className="text-sm text-muted-foreground">Nothing to preview.</p>
          )}
        </div>
      </TabsContent>
    </Tabs>
  );
}

"use client";

import { Search } from "lucide-react";
import Form from "next/form";
import { usePathname, useSearchParams } from "next/navigation";
import { useEffect, useRef } from "react";
import { Input } from "@/components/ui/input";

export function GlobalSearch() {
  const inputRef = useRef<HTMLInputElement>(null);
  const pathname = usePathname();
  const searchParams = useSearchParams();
  const currentQuery = pathname === "/search" ? (searchParams.get("q") ?? "") : "";

  // ⌘K / Ctrl+K focuses the search box from anywhere.
  useEffect(() => {
    function onKeyDown(event: KeyboardEvent) {
      if ((event.metaKey || event.ctrlKey) && event.key.toLowerCase() === "k") {
        event.preventDefault();
        inputRef.current?.focus();
        inputRef.current?.select();
      }
    }
    window.addEventListener("keydown", onKeyDown);
    return () => window.removeEventListener("keydown", onKeyDown);
  }, []);

  return (
    <Form action="/search" role="search" className="relative w-full max-w-xs">
      <Search aria-hidden className="pointer-events-none absolute top-1/2 left-2.5 size-4 -translate-y-1/2 text-muted-foreground" />
      <Input
        ref={inputRef}
        key={currentQuery}
        name="q"
        defaultValue={currentQuery}
        placeholder="Search issues…"
        aria-label="Search issues"
        autoComplete="off"
        className="h-8 bg-muted/50 pr-12 pl-8 shadow-none"
      />
      <kbd className="pointer-events-none absolute top-1/2 right-2 hidden -translate-y-1/2 rounded border bg-background px-1.5 font-mono text-[10px] text-muted-foreground sm:inline-block">
        ⌘K
      </kbd>
    </Form>
  );
}

"use client";

import { Users } from "lucide-react";
import { useTransition } from "react";
import { toast } from "sonner";
import { switchCurrentUser } from "@/actions/user-actions";
import { UserAvatar } from "@/components/shared/user-avatar";
import {
  DropdownMenu,
  DropdownMenuContent,

  DropdownMenuRadioGroup,

    startTransition(async () => {

          type="button"
          aria-label="Open user menu"
          className="rounded-full outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 focus-visible:ring-offset-background"
        >
          <UserAvatar user={currentUser} size="md" />
        </button>
      </DropdownMenuTrigger>
      <DropdownMenuContent align="end" className="w-60">
        <DropdownMenuLabel className="flex items-center gap-2.5 font-normal">
          <UserAvatar user={currentUser} size="md" />
          <div className="min-w-0">
            <p className="truncate text-sm font-medium">{currentUser.name}</p>
            <p className="truncate text-xs text-muted-foreground">{currentUser.email}</p>
          </div>
        </DropdownMenuLabel>
        <DropdownMenuSeparator />

          <DropdownMenuSubTrigger disabled={isPending}>
            <Users aria-hidden className="size-4" />

"use client";

import { DragDropContext, type DropResult } from "@hello-pangea/dnd";
import { useOptimistic, useTransition } from "react";
import { toast } from "sonner";
import { moveIssue } from "@/actions/issue-actions";
import { BoardColumn } from "@/components/board/board-column";
import { moveInColumns, neighborsAfterMove, type BoardMove, type Columns } from "@/lib/board";
import { ISSUE_STATUSES, isIssueStatus } from "@/lib/domain";
import type { BoardIssue } from "@/lib/queries/issues";

export function Board({ columns }: { columns: Columns<BoardIssue> }) {
  // The optimistic copy shows the drop instantly; when the action's
  // revalidation lands (or fails), React falls back to the server `columns`.
  const [optimisticColumns, applyMove] = useOptimistic(columns, moveInColumns<BoardIssue>);
  const [, startTransition] = useTransition();

  function handleDragEnd({ source, destination, draggableId }: DropResult) {
    if (!destination || !isIssueStatus(source.droppableId) || !isIssueStatus(destination.droppableId)) return;
    if (source.droppableId === destination.droppableId && source.index === destination.index) return;

    const move: BoardMove = {
      issueId: draggableId,
      from: { status: source.droppableId, index: source.index },
      to: { status: destination.droppableId, index: destination.index },
    };
    const { beforeId, afterId } = neighborsAfterMove(optimisticColumns, move);

    startTransition(async () => {
      applyMove(move);
      const result = await moveIssue({ issueId: move.issueId, toStatus: move.to.status, beforeId, afterId });
      if (!result.ok) toast.error(result.error);
    });
  }

  return (
    <DragDropContext onDragEnd={handleDragEnd}>
      <div className="flex min-w-max items-start gap-3">
        {ISSUE_STATUSES.map((status) => (
          <BoardColumn key={status} status={status} issues={optimisticColumns[status]} />
        ))}
      </div>
    </DragDropContext>
  );
}

```tsx
"use client";

import { LoaderCircle, Search, X } from "lucide-react";
import { usePathname, useRouter, useSearchParams } from "next/navigation";
import { useCallback, useEffect, useState, useTransition } from "react";
import { AssigneeFilter } from "@/components/board/assignee-filter";
import { TypeFilter } from "@/components/board/type-filter";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import type { IssueType } from "@/lib/domain";
import { EMPTY_FILTERS, MAX_QUERY_LENGTH, hasActiveFilters, writeFilters, type BoardFilters } from "@/lib/filters";
import type { UserSummary } from "@/lib/queries/users";

const SEARCH_DEBOUNCE_MS = 300;

function toggle<T>(values: T[], value: T): T[] {
  return values.includes(value) ? values.filter((v) => v !== value) : [...values, value];
}

export function FilterBar({ users, filters }: { users: UserSummary[]; filters: BoardFilters }) {
  const router = useRouter();
  const pathname = usePathname();
  const searchParams = useSearchParams();
  const [isPending, startTransition] = useTransition();

  // Local text so typing is instant; the URL is updated after a pause.
  const [query, setQuery] = useState(filters.q);
  const [pushedQuery, setPushedQuery] = useState<string | null>(null);
  const [previousUrlQuery, setPreviousUrlQuery] = useState(filters.q);
  if (filters.q !== previousUrlQuery) {
    // The URL changed. Adopt it unless it's the value this input just pushed
    // (e.g. Back button or "Clear" changed it from elsewhere).
    setPreviousUrlQuery(filters.q);
    if (filters.q !== pushedQuery) setQuery(filters.q);
  }

  const apply = useCallback(
    (next: BoardFilters) => {
      const params = writeFilters(searchParams.toString(), next).toString();
      startTransition(() => router.replace(`${pathname}${params ? `?${params}` : ""}`, { scroll: false }));
    },
    [pathname, router, searchParams],
  );

  useEffect(() => {
    const next = query.trim();
    if (next === filters.q) return;
    const timeout = setTimeout(() => {
      setPushedQuery(next);
      apply({ ...filters, q: next });
    }, SEARCH_DEBOUNCE_MS);
    return () => clearTimeout(timeout);
  }, [query, filters, apply]);

  function clearAll() {
    setQuery("");
    setPushedQuery("");
    apply(EMPTY_FILTERS);
  }

  return (
    <div className="flex flex-wrap items-center gap-3 px-6 pb-4">
      <div className="relative w-full max-w-60">
        {isPending ? (
          <LoaderCircle aria-hidden className="absolute top-1/2 left-2.5 size-4 -translate-y-1/2 animate-spin text-muted-foreground" />
        ) : (
          <Search aria-hidden className="absolute top-1/2 left-2.5 size-4 -translate-y-1/2 text-muted-foreground" />
        )}
        <Input
          value={query}
          onChange={(event) => setQuery(event.target.value)}
          placeholder="Search this board"
          aria-label="Filter issues by title or key"
          maxLength={MAX_QUERY_LENGTH}
          className="h-8 pl-8"
        />
      </div>

      <AssigneeFilter
        users={users}
        selectedIds={filters.assigneeIds}
        includeUnassigned={filters.includeUnassigned}
        onToggleUser={(userId) => apply({ ...filters, assigneeIds: toggle(filters.assigneeIds, userId) })}
        onToggleUnassigned={() => apply({ ...filters, includeUnassigned: !filters.includeUnassigned })}
      />

      <TypeFilter
        selected={filters.types}
        onToggle={(type: IssueType) => apply({ ...filters, types: toggle(filters.types, type) })}
      />

      {hasActiveFilters(filters) && (
        <Button variant="ghost" size="sm" className="h-8 text-muted-foreground" onClick={clearAll}>
          <X aria-hidden className="size-3.5" />
          Clear filters
        </Button>
      )}
    </div>
  );
}

"use client";

import { useOptimistic, useTransition } from "react";
import { toast } from "sonner";
import type { ActionResult } from "@/lib/action-result";

/**
 * Shows `next` immediately while `save` runs. On success the revalidated server
 * value replaces it; on failure a toast is shown and the old value returns.
 */
export function useOptimisticField<T>(serverValue: T, save: (value: T) => Promise<ActionResult<unknown>>) {
  const [value, setOptimisticValue] = useOptimistic(serverValue);
  const [isPending, startTransition] = useTransition();

  function setValue(next: T) {
    startTransition(async () => {
      setOptimisticValue(next);
      const result = await save(next);
      if (!result.ok) toast.error(result.error);
    });
  }

  return [value, setValue, isPending] as const;
}

"use client";

import { LoaderCircle } from "lucide-react";
import { useRef, useState } from "react";
import { toast } from "sonner";
import { updateIssue } from "@/actions/issue-actions";
import { Textarea } from "@/components/ui/textarea";
import { useOptimisticField } from "@/hooks/use-optimistic-field";
import { TITLE_MAX } from "@/lib/validation";

export function IssueTitleEditor({ issueId, title }: { issueId: string; title: string }) {
  const [value, save, isPending] = useOptimisticField(title, (next: string) =>
    updateIssue({ id: issueId, patch: { title: next } }),
  );
  const [isEditing, setIsEditing] = useState(false);
  const [draft, setDraft] = useState(title);
  // Escape unmounts the textarea, which can still fire blur; this skips that commit.
  const cancelledRef = useRef(false);

  function cancel() {
    cancelledRef.current = true;
    setIsEditing(false);
  }

  function commit() {
    if (cancelledRef.current) {
      cancelledRef.current = false;
      return;
    }
    setIsEditing(false);
    const next = draft.trim();
    if (!next) {
      toast.error("Title is required");
      return;
    }
    if (next !== value) save(next);
  }

  if (isEditing) {
    return (
      <Textarea
        data-inline-editor
        autoFocus
        value={draft}
        rows={2}
        maxLength={TITLE_MAX}
        aria-label="Issue title"
        onChange={(event) => setDraft(event.target.value)}
        onBlur={commit}
        onKeyDown={(event) => {
          if (event.key === "Enter" && !event.shiftKey) {
            event.preventDefault();
            commit();
          }
          if (event.key === "Escape") cancel();
        }}
        className="resize-none text-xl font-semibold tracking-tight md:text-xl"
      />
    );
  }

  return (
    <h2 className="text-xl font-semibold tracking-tight">
      <button
        type="button"
        onClick={() => {
          setDraft(value);
          setIsEditing(true);
        }}
        className="-mx-2 flex w-[calc(100%+1rem)] items-start gap-2 rounded-md px-2 py-1 text-left transition-colors hover:bg-muted/60 focus-visible:ring-2 focus-visible:ring-ring focus-visible:outline-none"
        aria-label={`Edit title: ${value}`}
      >
        <span className="min-w-0 flex-1 break-words">{value}</span>
        {isPending && <LoaderCircle aria-hidden className="mt-1.5 size-4 shrink-0 animate-spin text-muted-foreground" />}
      </button>
    </h2>
  );
}

"use client";

import { useOptimistic, useState, useTransition } from "react";
import { toast } from "sonner";
import { addComment } from "@/actions/comment-actions";
import { CommentForm } from "@/components/comments/comment-form";
import { CommentItem } from "@/components/comments/comment-item";
import type { CommentView } from "@/lib/queries/issues";
import type { UserSummary } from "@/lib/queries/users";

type PendingComment = CommentView & { isPending?: true };

type IssueCommentsProps = { issueId: string; comments: CommentView[]; currentUser: UserSummary };

export function IssueComments({ issueId, comments, currentUser }: IssueCommentsProps) {
  const [optimisticComments, addOptimisticComment] = useOptimistic<PendingComment[], PendingComment>(
    comments,
    (state, comment) => [...state, comment],
  );
  const [draft, setDraft] = useState("");
  const [, startTransition] = useTransition();

  function submit() {
    const content = draft.trim();
    if (!content) return;
    setDraft("");
    startTransition(async () => {
      addOptimisticComment({
        id: `pending-${crypto.randomUUID()}`,
        content,
        createdAt: new Date(),
        author: currentUser,
        isPending: true,
      });
      const result = await addComment({ issueId, content });
      if (!result.ok) {
        toast.error(result.error);
        setDraft(content);
      }
    });
  }

  return (
    <section aria-labelledby="activity-heading" className="space-y-4">
      <h3 id="activity-heading" className="text-sm font-semibold">
        Activity <span className="font-normal text-muted-foreground">({optimisticComments.length})</span>
      </h3>
      {optimisticComments.length === 0 ? (
        <p className="text-sm text-muted-foreground">No comments yet. Start the conversation.</p>
      ) : (
        <ul className="space-y-5">
          {optimisticComments.map((comment) => (
            <CommentItem
              key={comment.id}
              comment={comment}
              isPending={comment.isPending}
              canDelete={comment.author.id === currentUser.id}
            />
          ))}
        </ul>
      )}
      <CommentForm currentUser={currentUser} value={draft} onChange={setDraft} onSubmit={submit} />
    </section>
  );
}

type FormState = ActionResult<{ key: string }> | null;

export function CreateIssueDialog(props: CreateIssueDialogProps) {
  const [open, setOpen] = useState(false);
  // A new key per opening gives the form fresh state (values, errors, action state).
  const [formKey, setFormKey] = useState(0);

  function handleOpenChange(next: boolean) {
    setOpen(next);
    if (!next) setFormKey((key) => key + 1);

          <DialogDescription>Add a new issue to {props.projectKey}. Fields marked * are required.</DialogDescription>
        </DialogHeader>
        <CreateIssueForm key={formKey} {...props} onDone={() => handleOpenChange(false)} />
      </DialogContent>
    </Dialog>

function CreateIssueForm({
  projectId,
  projectKey,
  users,
  parentCandidates,
  onDone,
}: CreateIssueDialogProps & { onDone: () => void }) {
  const router = useRouter();
  const [type, setType] = useState<IssueType>("TASK");
  const [description, setDescription] = useState("");
  const [, startTransition] = useTransition();

  const [state, formAction, isPending] = useActionState<FormState, FormData>(async (_previous, formData) => {
    const result = await createIssue(createIssueInputFromForm(formData, projectId));
    if (!result.ok) return result;

    toast.success(`${result.data.key} created`, {
      action: { label: "View", onClick: () => router.push(boardIssueUrl(projectKey, result.data.key)) },
    });
    onDone();
    return null;
  }, null);

  const fieldErrors = state && !state.ok ? (state.fieldErrors ?? {}) : {};
  const formError = state && !state.ok && !state.fieldErrors ? state.error : null;
  const eligibleParents = parentCandidates.filter((candidate) => canBeParentOf(candidate.type, type));

  // Submit manually so React doesn't reset the form when validation fails.
  function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const formData = new FormData(event.currentTarget);
    startTransition(() => formAction(formData));
  }

  return (
    <form onSubmit={handleSubmit} className="space-y-4" noValidate>
      <div className="space-y-1.5">
        <Label htmlFor="create-title">Title *</Label>
        <Input id="create-title" name="title" autoFocus maxLength={TITLE_MAX} aria-invalid={!!fieldErrors.title} />
        <FieldError messages={fieldErrors.title} />
      </div>

      <div className="grid gap-4 sm:grid-cols-2">
        <div className="space-y-1.5">
          <Label htmlFor="create-type">Type</Label>
          <TypeSelect id="create-type" name="type" value={type} onValueChange={setType} />
          <FieldError messages={fieldErrors.type} />
        </div>
        <div className="space-y-1.5">
          <Label htmlFor="create-status">Status</Label>
          <StatusSelect id="create-status" name="status" defaultValue="TODO" />
        </div>
        <div className="space-y-1.5">
          <Label htmlFor="create-priority">Priority</Label>
          <PrioritySelect id="create-priority" name="priority" defaultValue="MEDIUM" />
        </div>
        <div className="space-y-1.5">
          <Label htmlFor="create-assignee">Assignee</Label>
          <AssigneeSelect id="create-assignee" name="assigneeId" users={users} defaultValue={null} />
          <FieldError messages={fieldErrors.assigneeId} />
        </div>
        <div className="space-y-1.5">
          <Label htmlFor="create-parent">Parent{type === "SUBTASK" ? " *" : ""}</Label>
          <ParentSelect
            // Remount when the type changes so an ineligible selection is cleared.
            key={type}
            id="create-parent"
            name="parentId"
            candidates={eligibleParents}
            defaultValue={null}
            disabled={type === "EPIC"}
          />
          <FieldError messages={fieldErrors.parentId} />
        </div>
        <div className="space-y-1.5">
          <Label htmlFor="create-points">Story points</Label>
          <Input
            id="create-points"
            name="storyPoints"
            type="number"
            inputMode="numeric"
            min={0}
            max={STORY_POINTS_MAX}
            placeholder="None"
            aria-invalid={!!fieldErrors.storyPoints}
          />
          <FieldError messages={fieldErrors.storyPoints} />
        </div>
      </div>

      <div className="space-y-1.5">
        <Label>Description</Label>
        <MarkdownEditor
          name="description"
          value={description}
          onChange={setDescription}
          maxLength={DESCRIPTION_MAX}
          aria-label="Description"
        />
        <FieldError messages={fieldErrors.description} />
      </div>

      {formError && (
        <p role="alert" className="rounded-md bg-destructive/10 px-3 py-2 text-sm text-destructive">
          {formError}
        </p>
      )}

      <DialogFooter>
        <Button type="button" variant="ghost" onClick={onDone}>
          Cancel
        </Button>
        <Button type="submit" disabled={isPending}>
          {isPending ? "Creating…" : "Create issue"}
        </Button>
      </DialogFooter>
    </form>
  );
}

  searchParams: Promise<SearchParamsRecord>;

      <FilterBar users={users} filters={filters} />

          const group = columns[status];
          return (
            <BacklogGroup
              key={status}
              status={status}
              count={group.length}
              points={group.reduce((sum, issue) => sum + (issue.storyPoints ?? 0), 0)}
            >
              {group.map((issue) => (
                <BacklogRow key={issue.id} issue={issue} href={`${basePath}${withIssueParam(query, issue.key)}`} />

            </BacklogGroup>
          );
        })}
      </div>
      {issueKey && <IssueDrawerSlot projectId={project.id} issueKey={issueKey} />}

## Architecture notes

- **Reads in Server Components, writes in Server Actions.** Pages call typed functions in
  `src/lib/queries/`. Mutations live in `src/actions/` and all go through `runAction`
  (`src/lib/action-result.ts`): zod validation → Prisma → `revalidatePath` → a typed
  `ActionResult` (`{ ok: true, data }` or `{ ok: false, error, fieldErrors? }`). Actions never throw to the client.
- **URL as state.** Filters (`?assignee=&type=&q=`) and the open issue (`?issue=`) live in the URL, so every view
  is server-rendered, shareable and works with the back button.
- **Optimistic UI.** Drag-and-drop, drawer fields and comments use `useOptimistic`; on failure React reverts to
  the server state and a toast explains why.
- **Fractional ordering.** Each issue stores a float `position` within its column. A drop takes the midpoint of
  its neighbors (one row updated); the server re-reads neighbors, appends when the client's view is stale, and
  renumbers a column when float precision runs out (`src/lib/position.ts`).
- **Issue keys.** `createIssue` increments `Project.issueCounter` inside a transaction; the row lock serializes
  concurrent creates so keys never collide.
- **Search.** A `pg_trgm` GIN index on `Issue.title` (extension enabled by `docker/init.sql`) backs
  case-insensitive substring search.
- **Tailwind v4.** Theme tokens live in `src/app/globals.css` (`@theme`); there is no `tailwind.config.ts`.
````
